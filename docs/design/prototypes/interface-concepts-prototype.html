Prototype of concepts 01 (The Charter) and 05 (The Table Read) from docs/design/interface-concepts.md. The other three — Prior Self, Tidelines, and the Loom — are sketched in the doc but not built here. Everything shown is a static walk-through of the doc's own worked examples (Mia's curriculum proposal; Rosa's funding memo); no AI is running. The pane targets the ~380px Word task pane; the writer's own prose is set in serif throughout, the tool's chrome in sans.
