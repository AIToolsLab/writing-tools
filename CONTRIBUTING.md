# Contributing

Research code from the [Thoughtful AI Lab](https://thoughtful-ai.com/) at Calvin
University. See [README.md](README.md) for what this repo is and how to run it.

Development conventions live next to the code they describe: [CLAUDE.md](CLAUDE.md)
for repo layout and workflow, then the `CLAUDE.md` / `README.md` in `frontend/`,
`backend/`, and `experiment/`. Architecture and design notes are in [docs/](docs/).

## Pull requests

- Keep each PR to one feature or fix, and link its issue (`Closes #123`).
- Get a teammate's review before merging, and let CI go green first.
- No branch-name or commit-message prefix scheme is enforced. Write a clear
  imperative subject line and don't worry beyond that.
